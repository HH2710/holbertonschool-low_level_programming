# C - Pointers, arrays and strings

This directory contains exercises about pointers in C.

## Files

- `main.h`: header file with the function prototypes
- `0-reset_to_98.c`: function that sets the value pointed to by an int pointer to 98

## Compilation

Files are compiled with:

    gcc -Wall -pedantic -Werror -Wextra -std=gnu89 0-main.c 0-reset_to_98.c -o 0-98
