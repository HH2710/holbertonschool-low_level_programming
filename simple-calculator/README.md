# Simple Calculator

## Description
A simple calculator written in C.

## Features
- Display a calculator menu.
- Add two numbers.
- Subtract two numbers.
- Multiply two numbers.
- Divide two numbers.
- Quit the program using option 0.

## Compilation
```bash
gcc -Wall -Werror -Wextra -pedantic calculator.c -o calculator
```

## Execution
```bash
./calculator
```
